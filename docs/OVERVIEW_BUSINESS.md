# KommoMCP — AI-ассистент для вашей CRM

> Управляйте CRM голосом разума, а не кликами мыши.

---

## Что это?

**KommoMCP** — Telegram-бот, который превращает вашу CRM Kommo в умного собеседника. Вместо десятков кликов по интерфейсу — одно сообщение в чат. Бот понимает естественный язык, сам находит нужные данные и выполняет операции.

```
Вы: «Покажи аналитику по всем воронкам за месяц»
Бот: [через 10 секунд — полный отчёт с конверсиями, 
      узкими местами и рекомендациями]
```

Никаких дашбордов, экспортов в Excel, ручных формул. Просто спросите — и получите ответ.

## Как это работает

```
💬 Сообщение в Telegram
        │
        ▼
   ┌─────────┐     Планировщик за <2ms определяет,
   │ 🎯 Plan │     какие из 54 инструментов нужны.
   └────┬────┘     Без нейросети — мгновенно и бесплатно.
        │
        ▼
   ┌─────────┐     AI получает только 2-6 нужных инструментов
   │ 🤖 AI   │     (вместо всех 54) и точный план действий.
   └────┬────┘     Точность: 95%+
        │
        ▼
   ┌─────────┐     Данные из Kommo API или локальной базы.
   │ 📊 Data │     Тяжёлая аналитика — на PostgreSQL.
   └────┬────┘
        │
        ▼
   📱 Ответ в Telegram
```

### Почему это работает лучше конкурентов

Обычные AI-боты получают **все** инструменты сразу и пытаются угадать, что вызвать. Это как дать человеку 54 кнопки без подписей.

KommoMCP использует **умный планировщик** — граф из 54 инструментов и 24 связей между ними. Планировщик за 2 миллисекунды:

1. Понимает намерение пользователя (аналитика? настройка? поиск?)
2. Находит нужные инструменты в графе
3. Разрешает зависимости (чтобы переместить сделку — сначала нужен список воронок)
4. Выстраивает порядок выполнения
5. Передаёт AI только то, что нужно

**Результат:** AI видит 4 кнопки с подписями вместо 54 без подписей. Точность вырастает с ~80% до 95%+.

## Масштабирование: один бот — много компаний

KommoMCP построен как **SaaS-платформа**. Каждый пользователь Telegram подключает свою CRM, и данные полностью изолированы:

```
        🤖 KommoMCP Bot
       ┌──────┼──────┐
       ▼      ▼      ▼
   Компания  Компания  Компания
      A         B         C
   (своя БД) (своя БД) (своя БД)
```

- **Изоляция данных** — каждая компания в своей базе
- **Несколько CRM** — один пользователь может подключить несколько аккаунтов Kommo
- **Свои ключи** — API-токены хранятся безопасно, у нас нет доступа к вашим данным
- **Подключение за 2 минуты** — `/connect`, ввести домен и токен, готово

## Безопасность

- **Подтверждение опасных операций** — удаление, массовые изменения требуют явного «Да»

## Интеграции

KommoMCP поддерживает **MCP-протокол** (Model Context Protocol от Anthropic) — открытый стандарт для подключения AI к внешним системам. Это значит, что наши 54 инструмента работают не только в Telegram, но и в:

- **Claude Desktop** — AI-ассистент от Anthropic
- **Cursor / Windsurf** — AI-редакторы кода
- **n8n** — платформа автоматизации
- Любой MCP-совместимый клиент
