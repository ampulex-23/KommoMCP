# KommoMCP — ИИ-ассистент для вашей CRM

## Что это?

KommoMCP — это интеллектуальный помощник, который позволяет управлять вашей CRM Kommo (amoCRM) через естественный диалог в Telegram. Вместо того чтобы кликать по интерфейсу, вы просто пишете боту что нужно сделать.

**Примеры команд:**
```
"Покажи аналитику воронки за месяц"
"Создай воронку Разработка с этапами: Лид, Квалификация, КП, Договор, Оплата"
"Кто из менеджеров закрыл больше всего сделок?"
"Найди все сделки без задач"
"Добавь тег VIP всем клиентам с чеком больше 100к"
```

## Как устроено?

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   Telegram Bot  │────▶│   AI + MCP Tools │────▶│   Kommo API     │
│   (ваш диалог)  │     │   (GPT-4o-mini)  │     │   (ваша CRM)    │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

1. **Вы пишете** боту в Telegram на естественном языке
2. **ИИ понимает** что вы хотите и выбирает нужные инструменты
3. **Инструменты выполняют** действия в вашей CRM через API
4. **Бот отвечает** результатом в удобном формате

## Что умеет?

### 📊 Аналитика
- Аналитика воронки продаж с конверсией по этапам
- Статистика по менеджерам (сделки, выручка, активность)
- Прогноз продаж на основе текущей воронки
- Отчёты по просроченным сделкам и задачам
- RFM-анализ клиентской базы

### 🔧 Управление CRM
- Создание/редактирование воронок и этапов
- Управление кастомными полями
- Массовые операции (перенос сделок, добавление тегов)
- Работа с контактами, компаниями, каталогами

### 🤖 Автоматизация
- Генерация тестовых данных для демо
- Полная зачистка тестовой CRM
- Управление вебхуками
- Поиск дубликатов контактов

### 💬 Умный диалог
- Бот помнит контекст разговора
- Понимает подтверждения ("Да", "Удали")
- Выполняет сложные многошаговые задачи

## Преимущества

### ⚡ Скорость
Вместо 10 кликов по интерфейсу — одно сообщение боту. Создание воронки с 5 этапами занимает 5 секунд вместо 2 минут.

### 🧠 Интеллект
ИИ понимает контекст и намерения. Не нужно знать точные названия полей или API — просто опишите что хотите.

### 📱 Доступность
Работает в Telegram — управляйте CRM с телефона, в дороге, без доступа к компьютеру.

### 🔒 Безопасность
- Ваши данные остаются в вашей CRM
- Бот работает через официальный API Kommo
- Деструктивные операции требуют подтверждения

### 📈 Масштабируемость
- RAG-архитектура для динамической загрузки инструментов
- Поддержка сотен инструментов без роста нагрузки
- Multi-tenant режим для SaaS

## Как начать?

1. **Напишите** боту `/start` в Telegram
2. **Подключите** вашу CRM (домен + API токен)
3. **Добавьте** OpenAI API ключ
4. **Готово!** Начинайте диалог с ботом

## Технологии

- **Python 3.11+** — асинхронная архитектура
- **MCP Protocol** — стандарт для AI-инструментов
- **OpenAI GPT-4o-mini** — быстрый и умный
- **Kommo API v4** — официальная интеграция
- **PostgreSQL** — для Big Data аналитики
