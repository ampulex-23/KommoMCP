## 2. Источники данных и инструменты сбора

### 2.1 Контур.Компас (рекомендуется как основной)

**Что делает:** Поиск ЮЛ и ИП по 68+ параметрам, включая ОКВЭД, регион, выручку, численность. Выгрузка с контактами (телефоны, email, ФИО руководителя).

**Почему подходит:** Можно сразу отфильтровать по нужным ОКВЭД + региону + выручке и получить готовый список с контактами.

**Тарифы:**

| Тариф | Выгрузка/мес | Цена/год | Комментарий |
|-------|-------------|----------|-------------|
| Бесплатный | 50 орг. | 0 ₽ | Для тестирования |
| Стандартный 500 | 500 орг. | ~14 400 ₽ | Достаточно для старта |
| Стандартный 1000 | 1 000 орг. | ~21 600 ₽ | Оптимальный |
| Расширенный 1000 | 1 000 орг. | ~28 700 ₽ | + ОКВЭД, лицензии, ОКПД2 |

**Что требуется от Димы:**
1. Зарегистрироваться на kontur.ru/compass
2. Активировать бесплатный доступ (50 выгрузок)
3. Протестировать выборку по ОКВЭД 46.37 + регион
4. Если результат устраивает — купить тариф «Стандартный 1000» (~21 600 ₽/год)

### 2.2 DaData API (для программного сбора и обогащения)

**Что делает:** API для поиска компаний по ИНН/ОГРН, подсказки по организациям с фильтрацией по ОКВЭД и региону. Возвращает: название, ИНН, адрес, ОКВЭД, ФИО руководителя, телефоны, email.

**Тарифы:**

| Тариф | Лимит/день | Цена/год | Комментарий |
|-------|-----------|----------|-------------|
| Бесплатный | 10 000 | 0 ₽ | Достаточно для сбора базы |
| Лёгкий | 50 000 | 14 000 ₽ | С подсказками |
| Расширенный | 100 000 | 28 000 ₽ | + численность, выручка |
| Максимальный | 200 000 | 56 000 ₽ | Полные данные |

**Ключевая возможность:** Фильтр `okved` в подсказках по организациям — можно программно собрать все компании с ОКВЭД 46.37 по регионам.

**Что требуется от Димы:**
1. Зарегистрироваться на dadata.ru
2. Получить API-токен (бесплатно)
3. Передать нам токен — мы интегрируем в бота

### 2.3 Rusprofile (ручной + парсинг)

**Что делает:** Бесплатный справочник юрлиц РФ. Поиск по ОКВЭД, региону, названию.

**Тарифы:**

| Тариф | Возможности | Цена |
|-------|------------|------|
| Бесплатный | Просмотр карточек, базовый поиск | 0 ₽ |
| Поиск клиентов (6000) | Выгрузка 6 000 организаций с контактами | 12 000 ₽ |
| Поиск клиентов (12000) | 12 000 организаций | 18 000 ₽ |

**Что требуется от Димы:** Зарегистрироваться, протестировать поиск по ОКВЭД 46.37.

### 2.4 2GIS API (для HoReCa сегмента)

**Что делает:** Поиск организаций по рубрике и геолокации. Идеально для сбора ресторанов, кафе, гостиниц в конкретных городах.

**Тарифы:** Бесплатный trial (100 запросов/день). Платный — по запросу.

**Что требуется от Димы:** Ничего — мы интегрируем в бота.

## 3. Обогащение лидов до контактов ЛПР

После сбора базовых данных компаний нужно найти:
- Телефон (мобильный) ЛПР
- Email ЛПР
- ФИО и должность

### Источники обогащения

| Сервис | Что даёт | Цена | Комментарий |
|--------|---------|------|-------------|
| DaData | ФИО руководителя, юр. телефон, email | Бесплатно (10к/день) | Базовые данные из ЕГРЮЛ |
| Контур.Компас | Телефоны, email, ФИО | В тарифе | Лучшее качество контактов |
| Trigga | Email сотрудников, SMTP-валидация | От 3 000 ₽/мес | Российский сервис аутрича |
| Hunter.io | Email по домену компании | $49/мес (500 запросов) | Хорош для компаний с сайтами |
| Rusprofile | ФИО руководителя, телефон | В тарифе | Данные из ЕГРЮЛ |
| 2GIS | Телефоны, адрес, часы работы | Бесплатный trial | Для HoReCa сегмента |
| hh.ru (парсинг) | Телефоны HR, email компании | Бесплатно | Компании с вакансиями |

### Рекомендуемая цепочка обогащения

```
1. Контур.Компас / DaData  →  ИНН, название, адрес, ФИО директора, юр. телефон
2. 2GIS                     →  Актуальный телефон, адрес (для HoReCa)
3. Hunter.io / Trigga       →  Email ЛПР (закупщик, коммерческий директор)
4. LinkedIn / hh.ru         →  Поиск конкретного ЛПР по должности
```
